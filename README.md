# Calendario de adviento (PHP · MVC)

- `index.php` controlador frontal · `app/Controllers` · `app/Models` · `app/Views` · `assets/` · `img/`
- Textos de las 24 puertas: `app/Models/Puertas.php` (edítalos con tus palabras).
- Fecha/zona horaria/clave de prueba: `config/config.php` (CAMBIA la clave).
- Audios opcionales: guarda `audio/dia5.mp3`, `audio/dia12.mp3`, etc. y aparecen solos en esa puerta.
- Probar otra fecha: `index.php?probar=TU_CLAVE&hoy=2026-12-10`
- Local: `php -S localhost:8000` en esta carpeta.
